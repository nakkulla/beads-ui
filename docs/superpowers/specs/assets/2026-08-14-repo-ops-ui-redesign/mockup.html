모든 실패는 세 가지 사람 용어로만 표시합니다: 검증 실패 · 배포 실패 · 중단됨. 세부 원인은 뒤에 문장으로 붙습니다("검증 실패 — GitHub에서 PR 상태를 읽지 못했습니다"). verify_cmd_failed 같은 원시 코드는 "세부" 접힘 안에서만 보입니다. 세션 실패 배너도 같은 규칙:

PR 대기 카드 — "정리 실패"가 아니라 "어디서 멈췄나"

카드의 정리 실패 칩은 멈춘 단계를 그대로 말하는 칩이 되고, 버튼은 "정리"가 아니라 정리 재개입니다. 카드 클릭 시 위 타임라인의 해당 항목으로 이동합니다.

설정 — 이 저장소의 선언과 Worker 자동 처리 기준
