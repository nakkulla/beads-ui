# 사용량 집계

## Context

- `UI-42l2-2`: 직접 세션 카드는 현재 참조 대화 전체 사용량을 보이되 Bead별 배분·워크스페이스 합계 가산을 하지 않는다.
- `UI-mscc`: 부모·자식의 검증된 직접 사용량을 중복 없이 합산하고 입증되지 않은 값은 추정 가산하지 않으며 미관측 범위는 부분 집계다.

## Decision

- 직접 세션 카드는 마지막 유효 `session_ref`가 가리키는 현재 로컬 대화 전체의 모델별 사용량과 연결된 위임을 표시하고 과거 참조는 합치지 않는다.
- 직접 세션 관측값은 카드 구독 수명 동안 공유 reader에서 준비하고 원문 경로와 대화 내용은 payload에 싣지 않는다.
- 같은 대화를 여러 카드가 참조해도 그 값은 Bead별 또는 워크스페이스 비용 KPI에 자동 가산하지 않는다.
- 자료가 없거나 가격을 확정할 수 없는 부분은 0원으로 만들지 않고 생략 또는 `단가 없음`으로 남긴다.
- `codex_children`은 UI 소유 관측 기록이다. workflow metadata·실행 영수증·게이트 입력으로 쓰지 않고 과거 기록의 필드 부재는 미관측으로 읽는다.
- 원천은 해당 attempt의 root rollout과 부모 연결이 root까지 확인된 자식 rollout이다. 기존 계정 격리와 경로 해석을 쓰고, 관계없는 전사를 수집하거나 exec JSONL·hook으로 자식 관계를 추정하지 않는다. 자식별 행과 누적 관측값 교체·미관측값 보존을 따른다.
- 부모와 자식의 검증된 직접 사용량을 각각 한 번 합산한다. 응답 식별자로 중복을 제거하고 모델·turn·attempt 경계를 보존한다. 누적 스냅샷은 대조값이다. 재개·자식 재사용·중첩 자식·동일 실행의 외부 영수증도 실행 연결과 범위 증거로 중복을 제거한다.
- 직접 귀속·경계·겹침을 입증하지 못한 값은 총액에 추정 가산하지 않고, 확인된 부분 비용과 누락 사유를 함께 표시하며 미관측과 명시적 0을 구별한다. 모델 확인과 관측 완전성은 별개이고 모델이 확인된 부분 구간에는 현재 설정 단가를 적용한다.
- 공용 투영이 부모·자식·총합을 만들고 카드·상세·비교·워크스페이스가 같은 기여와 부분 여부를 소비한다. 자식별 토큰·비용은 위임 행과 상세에도 표시한다. Claude의 이미 포함된 자식 비용은 다시 더하지 않는다.
- spawn 도구 완료는 자식 완료가 아니다. 성공·실패·중단은 실제 수명 증거로 구분하고, 종료와 drain 증거가 없는 범위는 부분 집계로 남긴다.
- 종료 저장은 attempt/Bead 이력 경계가 소유한다. 과거 보완은 정확히 연결된 세션의 비동기 구독·조회 준비 단계에서 하고, 동기 투영의 전사 스캔이나 전체 이력 일괄 마이그레이션을 만들지 않는다.

## Consequences

- 사용량 집계가 한 행으로 읽힌다. 되돌리려면 공용 투영·카드·비교·워크스페이스 KPI가 함께 움직인다.
- 흡수한 두 ADR의 조항은 전부 승계했고 폐기한 조항은 없다.
