# 부모와 자식의 직접 사용량을 중복 없이 합산하고 불완전한 범위는 부분 집계로 표시한다

## Context

ADR UI-42l2는 부모와 자식의 사용량 중복 여부를 입증하지 못해 자식별 금액을
표시하되 합계에서 제외했다. 실제 Codex 기록을 응답별로 대조하니 부모와 자식의
직접 사용량이 구분되고 각 합이 대화의 누적값과 일치했다. 이 근거를 사용해
확인된 소비를 합산하되, 모든 버전과 과거 기록이 같은 증거를 가진다고 가정하지 않는다.

저장·표시·비교의 합계 의미를 함께 바꾸므로 되돌리는 비용이 있고, 맥락 없이 보면
과거 금액이 달라지는 이유가 불명확하다. 단순 누적값 합산이나 계속 합산 제외하는
대안보다 검증과 부분 표시의 비용을 감수하는 절충을 선택한다.

## Decision

- `codex_children`은 UI 소유 관측 기록이다. workflow metadata·실행 영수증·게이트
  입력으로 사용하지 않으며 과거 기록의 필드 부재는 미관측으로 읽는다.
- 원천은 해당 attempt의 root rollout과 부모 연결이 root까지 확인된 자식 rollout이다.
  기존 계정 격리와 경로 해석을 사용하고, 관계없는 전사를 수집하거나 exec JSONL·hook으로
  자식 관계를 추정하지 않는다. 자식별 행과 누적 관측값 교체·미관측값 보존은 유지한다.
- 부모와 자식의 검증된 직접 사용량을 각각 한 번 합산한다. 응답 식별자로 중복을
  제거하고 모델·turn·attempt 경계를 보존한다. 누적 스냅샷은 대조값이며 응답별
  기여에 추가하지 않는다. 재개·자식 재사용·중첩 자식·동일 실행의 외부 영수증도
  실제 실행 연결과 범위 증거로 중복을 제거한다.
- 직접 귀속·경계·겹침을 입증하지 못한 값은 총액에 추정 가산하지 않는다. 확인된
  부분 비용과 누락 사유를 함께 표시하며 미관측과 명시적 0을 구별한다. 모델 확인과
  관측 완전성은 별개다. 모델이 확인된 부분 구간에는 현재 설정 단가를 적용한다.
- 공용 투영이 부모·자식·총합을 만들고 카드·상세·비교·워크스페이스가 같은 기여와
  부분 여부를 소비한다. 자식별 토큰·비용은 기존 위임 행과 상세에도 표시한다.
  직접 세션은 현재 참조 대화 범위이며 Bead별 배분과 워크스페이스 자동 가산을 하지
  않는 ADR UI-42l2-2를 유지한다. Claude의 이미 포함된 자식 비용도 다시 더하지 않는다.
- spawn 도구 완료는 자식 완료가 아니다. 성공·실패·중단은 실제 수명 증거로 구분하고,
  부모 종료만으로 집계를 완전하다고 판정하지 않는다. 종료와 drain 증거가 없는 범위는
  부분 집계로 남긴다.
- 종료 저장은 기존 attempt/Bead 이력 경계가 소유한다. 과거 보완은 정확히 연결된
  세션의 비동기 구독·조회 준비 단계에서 공유하며, 동기 투영의 전사 스캔이나 전체
  이력 일괄 마이그레이션을 만들지 않는다.

## Consequences

검증 가능한 자식 소비가 과거 합계에도 포함되어 금액이 달라질 수 있다. 가격을
계산할 수 있다는 사실만으로 관측 범위가 완전해지지 않으므로 부분 집계 설명이
카드부터 비교 중앙값까지 유지되어야 한다. 원본이 없거나 경계를 증명하지 못한
기록에서는 확인된 값만 제공하며, 전체 청구액을 추정하지 않는다.
