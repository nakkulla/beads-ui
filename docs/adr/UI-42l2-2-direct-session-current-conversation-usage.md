# 직접 세션 카드는 현재 참조 대화 전체 사용량을 표시하고 워크스페이스 합계에는 가산하지 않는다

## Context

하나의 직접 대화는 여러 Bead를 다룰 수 있고, `session_ref`는 현재 Bead가 그
대화를 참조한다는 사실만 말한다. 전사에는 토큰을 Bead별로 나눌 검증된 경계가
없다. 표시를 생략하면 사용자는 진행 중인 직접 세션의 실제 사용량과 위임 상태를
볼 수 없고, Bead 비용으로 나누면 근거 없는 회계값이 된다.

## Decision

- 직접 세션 카드는 마지막 유효 `session_ref`가 가리키는 현재 로컬 대화 전체의
  모델별 사용량과 연결된 위임을 표시한다. 과거 참조는 합치지 않는다.
- 관측값은 카드 구독 수명 동안 공유 reader에서 준비하며 원문 경로와 대화 내용은
  payload에 싣지 않는다.
- 같은 대화를 여러 카드가 참조해도 그 값은 Bead별 또는 워크스페이스 비용 KPI에
  자동 가산하지 않는다.
- 자료가 없거나 가격을 확정할 수 없는 부분은 0원으로 만들지 않고 생략 또는
  `단가 없음`으로 남긴다.

## Consequences

직접 세션 카드의 숫자는 Bead 작업량이 아니라 현재 대화 전체 범위다. 따라서 카드
값과 워크스페이스 합계가 다를 수 있다. 대가는 대화의 일부를 Bead별로 비교할 수
없다는 점이며, 근거 없는 배분을 피하고 실제 관측 범위를 그대로 보여 주는 쪽을
택한다.
