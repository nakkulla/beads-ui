서버 규칙

  1. 서버는 main에 있고 GitHub main과 같은 코드만 실행한다
  2. 서버에서는 어떤 브랜치도 커밋·push하지 않는다

  4. 잡 실패는 JobState로 판정한다. 메모리 초과로 죽은 잡도 종료 코드가 0으로 찍힐 수 있다
